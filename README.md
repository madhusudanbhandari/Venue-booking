# Venue-booking
Basic Venue Booking app

Venue Booking System is a platform that allows users to browse, book, and manage venues seamlessly. It also provides venue owners with a dashboard to manage their venues and track bookings efficiently.

User Module:

Browse available venues

View venue details

Book venues and track booking status

Owner Module:

Add, edit, and manage venues

View booking requests

Owner dashboard for quick access to venue analytics

Authentication & Security:

Secure login and registration 

Role-based access control (User, Owner)

Real-Time Updates:

Live updates of venue availability

Notifications for booking confirmations
